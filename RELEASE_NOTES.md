# Deer Crossings v1.0.04 — Release Notes

This is a material-only lighting compatibility update. Deer should retain more readable shading on systems using stock Assetto Corsa weather/lighting with CSP, while preserving the current calibrated texture and avoiding the earlier overbright look.

## Changes
- ksAmbient: 0.10 → 0.17
- ksDiffuse: 0.30 → 0.33
- ksSpecular remains 0.00
- No gameplay or physics changes from v1.0.03.
