# Installation — Deer Crossings v1.0.04

## Content Manager

1. Download `DeerCrossings-v1.0.04.zip`.
2. Drag the ZIP onto Content Manager.
3. Choose **Install**.
4. Start a singleplayer session.
5. Open the Assetto Corsa app sidebar.
6. Select **Deer Crossings**.

## Manual installation

Extract the ZIP to the Assetto Corsa root directory. The final path must be:

`assettocorsa/apps/lua/DeerCrossings/`

The folder should contain `DeerCrossings.lua`, `DeerImpactWorker.lua`, `manifest.ini`, `icon.png`, documentation files and the `assets` folder.

## Updating an older version

Delete or back up the old `apps/lua/DeerCrossings` folder first, then install the complete new package. Do not mix files from different versions.

Also disable/remove the old `apps/lua/DeerTest/` development app if it is still installed.

## App icon not refreshing

If Assetto Corsa still shows an old/default icon after updating, fully close Assetto Corsa and Content Manager, then reopen them to refresh the app-list cache.
